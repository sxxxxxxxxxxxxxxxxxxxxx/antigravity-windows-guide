怎么对号（先看这三句）

• 账号没资格：先查地区与资格，再查年龄认证，不要先反复注入。

• unexpected issue / 网络超时：就是客户端没真正走通代理——请按 第三章网络配置 处理（Tun / ProxyBridge 等）。

• Further action / 扫码：登录阶段人机验证；年龄认证在「账号没资格」那条处理。不要狂扫十几次。

• 对话时报 400 且含 User location is not supported：出口地区不被支持，先换日/新等干净节点再重开客户端 → 点此直达排障 Q3。

• 桌面图标偏白多半是 2.0，偏黑多半是 IDE（看桌面快捷方式，不是软件内部主题）；发消息一直转圈：优先当网络未接管，不要先反复注入账号。
